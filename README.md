# 유튜브 트레일러 정보 기반 개봉 첫 주말 실적 예측

석사학위논문 프로젝트 페이지 · 서정범 · 고려대학교 SW·AI 융합대학원 빅데이터융합학과

트레일러 공개 후 7일 이내의 댓글과 트레일러 영상만으로 북미 개봉 첫 주말 실적(OW)을
예측하는 6-View MvFS 모델을 다룹니다.

- 분석 대상 217편 (학습 195 / 평가 22)
- 최종 사용 댓글 2,725,731건
- 최종 평가 RMSE $23.86M · MAPE 38.8%

## 구성

```
index.html        단일 페이지 (한국어·영어 전환)
```
